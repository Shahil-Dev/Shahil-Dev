## &nbsp;`/` &nbsp; Selected Work

<br/>

### &nbsp;`01` — Zenith Care &nbsp;·&nbsp; *Hospital Management System*

<br/>

> A comprehensive, role-based healthcare platform engineered for clinical efficiency and operational clarity.

- **Patient Management** — Full lifecycle tracking: registration, appointment scheduling, medical history, discharge
- **Role-Based Access Control** — Distinct permission layers for Admin, Doctor, and Patient roles via JWT authentication
- **Appointment Engine** — Real-time slot management with conflict resolution and status workflows
- **Dashboard Architecture** — Analytics-driven admin panel with occupancy, billing, and staff metrics
- **Billing Module** — Automated invoice generation tied to appointment and service records

<br/>

`Next.js` &nbsp;`TypeScript` &nbsp;`Tailwind CSS` &nbsp;`Node.js` &nbsp;`Express.js` &nbsp;`Prisma ORM` &nbsp;`PostgreSQL` &nbsp;`JWT` &nbsp;`Redux Toolkit`

<br/>

---

### &nbsp;`02` — Foodio &nbsp;·&nbsp; *Food Delivery Backend API*

<br/>

> A production-grade RESTful backend engineered for speed, clarity, and scalable food delivery operations.

- **Restaurant & Menu API** — Structured endpoints for item management, category nesting, and availability toggles
- **Order Lifecycle Engine** — State-machine-driven order flow: placed → confirmed → dispatched → delivered
- **Auth System** — Stateless JWT authentication with refresh token rotation and role separation (Customer / Vendor / Admin)
- **Search & Filtering** — Query-optimized endpoints for location-aware restaurant discovery and menu search
- **Delivery Tracking** — Status update pipeline with timestamped event logging per order

<br/>

`Node.js` &nbsp;`Express.js` &nbsp;`MongoDB` &nbsp;`JWT` &nbsp;`REST API`
