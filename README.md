### 🏗️ Flagship Architecture & Case Studies

#### 🏥 Zenith Care — Multi-Tenant Hospital Ecosystem
*A secure, audit-ready clinical workflow engine built to preserve data integrity across complex organizational structures.*
*   **Implementation:** Engineered a strict Multi-tenant Role-Based Access Control (RBAC) system safeguarding sensitive patient health records.
*   **Persistence Layer:** Modeled highly relational schemas via Prisma ORM connected to a PostgreSQL instance, implementing atomic transactions to prevent partial state corruption.
*   **Security:** Anchored systems with robust token authentication and continuous audit logging for trace capabilities.
*   **Stack:** `Next.js` • `TypeScript` • `Node.js` • `Express` • `Prisma` • `PostgreSQL`

#### 🍔 Foodio — High-Throughput Logistics Engine
*An event-driven backend system optimized for low-latency ordering, rapid dispatch states, and predictable failure isolation.*
*   **Optimization:** Introduced a caching layer via Redis to isolate database operations, reducing lookup latency for fast-moving menu data.
*   **Resilience:** Formulated robust database indexing profiles across MongoDB and PostgreSQL collections to prevent performance degradation under concurrent read/write loads.
*   **Architecture:** Structured clean, decoupled RESTful route patterns emphasizing predictable API contracts and informative error boundaries.
*   **Stack:** `Node.js` • `Express` • `MongoDB` • `PostgreSQL` • `Prisma` • `Redis`
